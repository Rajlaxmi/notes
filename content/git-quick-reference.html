Undoing things

SituationCommand
Unstage a filegit restore --staged file
Discard working changesgit restore file
Amend last commitgit commit --amend
Undo last commit, keep changesgit reset --soft HEAD~1
Undo last commit, discard changesgit reset --hard HEAD~1
Recover a "lost" commitgit reflog, then git reset --hard <sha>

Under the hood. git reset --hard only moves the branch pointer and rewrites the working tree — the old commits are still in the object database, reachable through git reflog until garbage collection runs (roughly 90 days later by default). A "lost" commit is almost never actually lost.

Inspecting history

git log --oneline --graph --decorate --all   # the shape of everything
git show <sha>                                # one commit in full
git blame file                               # who last touched each line
git diff main...feature-x                     # what feature-x adds vs main
